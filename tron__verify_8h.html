Detailed Description

Check that a node-built TRON transaction spends what we asked for.

The TRON full node serialises the transaction (protobuf) on our behalf, so the firmware must confirm the bytes before handing the digest to the card. Kept free of ESP-IDF dependencies so it can be self-checked on a host — see the build line in tron_verify.cpp.
